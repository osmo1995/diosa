## 🎯 Project Overview

**What is Diosa Studio?**
A luxury hair extension salon in Yorkville, Toronto. This is their website featuring:
- Service showcase (Tape-In, Keratin Bond, Hand-Tied, Sew-In)
- AI-powered style preview generator (virtual try-on)
- Before/After transformation gallery
- Booking consultation flow
- Educational content (process, aftercare, methods)

**Target Audience:** High-end clientele seeking premium, integrity-first hair extensions

## 🚦 Deployment Process

### Hero/CTA AVIF note (important)
The homepage hero and CTA use `<OptimizedImage preferAvif>` which requests `.avif` assets under `/exports/...`.
Those AVIF files are generated at build time by `scripts/generateAvif.mjs` and must be copied into `public/exports`.
This is handled by `scripts/copyExportsToPublic.mjs` (runs in `npm run prebuild`).
If you deploy with Vercel CLI, avoid `--prebuilt` unless you have run `npm run build` (which runs prebuild).

1. Run `npx tsc --noEmit` to find TypeScript errors
2. Check `npm install` completed successfully
3. Verify Node.js version (need v20+)
